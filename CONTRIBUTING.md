# Contribuir

Este repositorio es una demostración técnica personal y un caso de estudio de
portfolio. No busca colaboradores ni acepta contribuciones de código externas.

La razón no es de política sino de alcance: el proyecto describe una propuesta
concreta para el Colegio de Enfermeros del Perú, y su valor depende de que las
decisiones de arquitectura y seguridad respondan a un criterio único y
documentado. Cada una queda registrada como ADR antes de implementarse.

## Qué sí es bienvenido

**Vulnerabilidades de seguridad.** Se reportan en privado siguiendo
[`SECURITY.md`](SECURITY.md), nunca en un issue público.

**Errores y correcciones de documentación.** Un issue describiendo el problema
es suficiente. No hace falta abrir un pull request.

**Preguntas sobre las decisiones tomadas.** Las decisiones publicables están
explicadas en el README y en la política de seguridad; si algo no se entiende,
probablemente sea un defecto de la documentación.

## Qué no se acepta

- Pull requests con funcionalidad nueva o cambios de arquitectura.
- Peticiones de soporte para desplegar una copia propia.
- Reportes que incluyan datos personales reales. Los datos de la demostración
  son sintéticos y deben seguir siéndolo en cualquier evidencia adjunta.

## Si aún así quiere partir del código

El código se distribuye bajo licencia MIT y puede usarse libremente. La licencia
no concede derechos sobre nombres, logotipos ni marcas de terceros, y una copia
desplegada no debe presentarse como servicio oficial de ninguna institucion.
