# Política de seguridad

## Reporte responsable

No publique vulnerabilidades, credenciales ni datos personales en un issue. Mientras el proyecto permanezca como demostración personal, utilice un canal privado definido por el responsable del repositorio en GitHub Security Advisories.

## Alcance actual

La rama `main` y el dominio demo son las superficies soportadas. Los datos incluidos son sintéticos. La aplicación no emite constancias oficiales ni consulta el padrón real del CEP.

## Tiempos objetivo

- Crítico: evaluación inicial en 24 horas.
- Alto: evaluación inicial en 3 días hábiles.
- Medio o bajo: inclusión en el siguiente ciclo planificado.

Las credenciales expuestas se revocan inmediatamente, sin esperar el análisis completo del incidente.
